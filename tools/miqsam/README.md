# مِقسام ✦ مقسّم الآيات الأسطوري (أداة تقسيم الصوت)

نسخة من تضمين داخل مشروع learn-quran-kids (المصدر الأصلي: `H:\YOUCEF\مجلد جديد`).

## ما هي؟
أداة محلية (HTML/JS خالص، تعمل 100% على الجهاز بدون رفع) تقسم تلاوة السورة الكاملة
إلى آيات منفصلة تلقائياً عبر تحليل **السكتات + حدّة الصوت**، مع تمييز
المعلّم/الطفل، موجّه تفاعلية للتدقيق اليدوي، وتنزيل النتيجة ZIP.

## طريقة الاستخدام
افتح `index.html` في المتصفح، أو شغّل خادماً بسيطاً:

```bash
cd tools/miqsam
python -m http.server 8080
# ثم افتح http://localhost:8080
```

## الاختبار بالملفات المحلية
يمكن رفع ملفات التلاوة من المجلد الاختباري مباشرةً في المتصفح:
`H:\التلاوة التعليمية - أمين حاج أيوب mp3` (mp3 مرقّمة 1–114 بأرقام السور)
— اسحب الملف أو اختره من زر «مجلد التلاوة» للتقسيم الجماعي.

## الاختبارات (tests)
```bash
cd tools/miqsam
npm test        # أو: node tests/run-tests.js
```

## كيف ترتبط بالمشروع الرئيسي؟
- مخرجات الأداة (JSON زمني) يمكن لصقها في **إعداد التوقيت** (`/timings`)
  أو **ربط الصوت بالتظليل** (`/link`) داخل التطبيق لحفظها على السيرفر
  (`Supabase store` → جدول `store`).
- ترتيب العمل المقترح: ① صوّر صفحات المصحف وارفعها في **المعايرة** (`/calibrate`)
  → ② قسّم الصوت هنا بالآيات → ③ اربط النتيجة بالصفحات في `/link`.
